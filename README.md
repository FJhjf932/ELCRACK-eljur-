# ELCRACK-eljur-

Скрипт на Python для автоматизации действий в электронном дневнике ЭлЖур (eljur.gospmr.org). Позволяет отправлять массовые рассылки сообщений, сканирует и создаёт календари.

## Инструкция по использованию

### 1. Авторизация
- **login>>** — логин от аккаунта ЭлЖур
- **password>>** — пароль от аккаунта ЭлЖур

При успешной авторизации скрипт определит домен пользователя и перенаправит в главное меню. В случае ошибки потребуется повторить ввод.

### 2. Главное меню
В меню доступен выбор следующих пунктов:

1. **message boom** — модуль массовой отправки сообщений.
2. **scan calendar** — модуль массового сканирование календарей.
3. **calendar boom** — модуль массовой публикации событий.
4. **brute online** — зарезервированный пункт меню (выход в текущей версии).
99. **exit** — завершение работы скрипта.

### 3. Отправка сообщений (message boom)
После выбора пункта `1` скрипт запрашивает данные по порядку:
1. `n>>` — количество получателей.
2. `id_N>>` — ID каждого получателя (по очереди).
3. `description>>` — текст отправляемого сообщения.
4. `title>>` — тема сообщения.
5. `N>>` — количество повторов (циклов) отправки.

Скрипт автоматически получает актуальный CSRF-токен из формы и производит отправку сообщений по всем указанным ID.

### 4. сканирование календарей (scan calendar)
После выбора пункта `2` скрипт запрашивает данные по порядку:
1. `min>>` — c
2. `max>>` — до
3. `log_file>>` — адрес файла, в котором буде результат.

Скрипт заполнит txt файл ответа информацией о найденных календарях.

## Внутренние функции скрипта

- `ses_update()` — генерирует случайный User-Agent для обхода простых блокировок.
- `reg(login, password)` — отправляет POST-запрос на авторизацию и получает домен.
- `newcal(...)` — API-функция для создания событий в календаре.
- `razved_cal(id)` — API-функция для получения информации о конкретном событии календаря.
- `go_mess(...)` — функция отправки личного сообщения с поддержкой CSRF.
